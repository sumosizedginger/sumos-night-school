# Night School

A beginner tarot studio. Study the Rider–Waite–Smith method, then do a reading with the same deck.

Study is the class. A reading says what the draw does to your question. On a finished draw, **Teach this draw** is the method for those cards only. **Go deeper** is optional and stays on the reading.

Pictures and wording are original. Pamela Colman Smith drew the 1909 deck. Arthur Edward Waite commissioned it and wrote *The Pictorial Key to the Tarot*.

```bash
npm install
npm run dev
```

Progress and reading history stay in the browser.
